# Security

## Supported version

Only the latest public release receives fixes.

## Reporting a vulnerability

Use GitHub's private vulnerability reporting or open a private Security Advisory in this repository. Do not publish exploit details in a public issue.

The application has no updater, telemetry, account system, or network service. It modifies the locally selected Terraria executable or installs the bundled client-side tModLoader bridge. Verify downloads against `SHA256SUMS.txt`.
