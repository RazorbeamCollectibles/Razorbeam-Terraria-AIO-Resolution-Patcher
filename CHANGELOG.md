# Changelog

All notable changes use [Semantic Versioning](https://semver.org/).

## 1.0.0 — 2026-09-06

- Corrected centered tModLoader input and cursor alignment with SilkyUIFramework and ImproveGame.
- Added in-game guidance to configure the display bridge in the desktop patcher.
- Disabled unsupported tModLoader title-message suppression.

- First public release.
- Added arbitrary signed multi-display layouts for Terraria and tModLoader.
- Added scale-aware centered UI and input mapping.
- Preserved interactive crafting, minimap, health, mana, settings, and mod interface layers.
- Removed forced ultrawide zoom behavior from tModLoader.
- Added verified vanilla executable backups and transactional tModLoader configuration restore.
- Added optional non-activating recovery of minimized game windows without always-on-top behavior.
- Added stable window titles, vanilla startup splash skipping, display detection, and offline diagnostic exports.
- Added dedicated tModLoader icons and Steam Workshop publishing assets.
